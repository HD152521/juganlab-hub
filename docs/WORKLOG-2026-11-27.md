## 1. 홈 하단

- **문제:** 제보 안내가 어두운 큰 상자로 빈 공간에 혼자 떠 보였다. 처음에는 상자를 작게 줄였지만 같은 문제가 남았다.
- **변경:** 상자를 없애고 홈 footer 맨 위 한 줄로 옮겼다(`id="contact"` 는 유지). "내가 만든 것도 올려 보세요" 블록은 삭제했다. 메뉴·첫 화면·footer 의 올리기 링크는 건드리지 않았다.
- **파일:** `src/index.template.html`, `src/styles.css`, `src/app.js`

## 2. 작품 목록 필터

- **문제:** 검색창, 종류 버튼, 분야 선택칸, 정렬 선택칸이 한 막대에 섞여 쓰기 불편했다. 작품이 0개인 종류도 보였다.
- **참고한 화면:** GitHub Marketplace(왼쪽 목록 + 드롭다운 버튼), Vercel Templates(필터 패널), Firefox 부가기능(왼쪽 선택칸), Raycast Store(확인한 윗부분은 큰 검색창).
- **검토한 안:** A 탭 + 한 줄 / B 왼쪽 목록 / C 필터 버튼. 선택칸을 열지 않고 한 번에 거를 수 있고 작품이 적어도 어색하지 않은 **A** 로 정했다. 분야가 많이 늘면 B 를 다시 검토한다.
- **변경:**
  - 종류는 밑줄 탭, 분야는 버튼. 작품이 하나도 없는 종류·분야는 나오지 않는다.
  - 검색과 정렬은 탭 오른쪽. 640px 이하에서는 아래 줄로 내려가도록 스타일을 넣었다.
  - 전체 개수는 탭에 있으므로 개수 줄은 거를 때만 보인다(화면 낭독기용 요소는 항상 유지).
  - 겹쳐 있던 옛 필터 스타일을 지웠다. `.market-search` 기본 스타일은 UI 도감도 써서 남겼고, 새 스타일은 `.market-bar` 안에만 적용한다.
- **영향 범위:** `/works` 와 영어 페이지가 같은 필터를 쓴다.
- **파일:** `lib/market.mjs`, `src/market.js`, `src/styles.css`, `test/market-bar.test.mjs`(새 테스트 3개)

## 3. UI 도감 중복

- **문제:** 홈 도구함에서는 "UI 도감"과 "개발 참고"가 나란한 카드인데, "개발 참고" 안에 UI 도감이 또 있었다.
- **변경:** `/learn` 에서 UI 도감 카드를 빼고 번호·소개 문구·콘솔 `learn` 명령 설명·`DIRECTION.md` 사이트 구조를 맞췄다. 홈 카드와 `/dojang/ui` 페이지는 남겼다.
- **파일:** `lib/learn.mjs`, `src/app.js`, `docs/DIRECTION.md`

## 로컬 실행

```bash
git pull --ff-only
node build.mjs     # dist/ 생성
npm run preview    # http://localhost:4173
```

- 실행 전에 원격 최신 상태를 먼저 받는다.
- 포트는 4173 을 계속 쓴다. 이미 떠 있는 미리보기 서버가 있으면 새로 띄우지 않고 `node build.mjs` 만 다시 실행한 뒤 새로고침한다(서버가 `dist/` 를 디스크에서 읽는다).
