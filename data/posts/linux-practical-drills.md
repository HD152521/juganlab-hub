리눅스 셸 연습장을 공개한 뒤 바로 다음으로 만든 것이 실기 대비 문제입니다. 리눅스마스터 1급 2차의 실기는 작업식입니다. "이 디렉터리를 이런 권한으로 만들어라", "이 사용자를 이 그룹에 넣어라"처럼 조건이 주어지고, 수험자는 그 결과를 실제 시스템에 만들어 내야 합니다. 객관식 문제은행으로는 연습할 수 없는 부분이라, 셸 연습장 위에 작업형 문제를 얹었습니다.

## 문제 구성

문제는 두 묶음, 모두 15개입니다.

- **실기 P1 권한·소유권 7선**: 스크립트 권한 지정, 처음부터 권한을 정해 디렉터리 만들기, umask 로 기본 권한 정하기, SetUID 붙이기, 그룹 공유 디렉터리, 누구나 쓰되 남의 파일은 못 지우게 하기, 디렉터리 통째로 소유권 넘기기.
- **실기 P2 계정·검색 8선**: 조건에 맞춰 사용자 만들기, 보조 그룹 더하기, 계정 잠그기, 홈 디렉터리까지 지우기, GID 를 정해 그룹 만들기, SetUID 파일 목록 저장, 조건에 맞는 줄 수 세기, 특정 사용자 파일 한꺼번에 지우기.

문항마다 처음 상태가 따로 있습니다. 문제에 필요한 사용자·그룹·파일이 미리 갖춰진 셸에서 시작하므로, 수험자는 조건을 읽고 바로 작업에 들어갈 수 있습니다. 휴대폰처럼 화면이 좁을 때는 문제의 조건까지 터미널 위 띠에 붙여, 조건을 보면서 입력할 수 있게 했습니다.

## 왜 결과로 채점하나

명령 문자열을 정답과 비교하면 구현은 쉽습니다. 하지만 같은 결과를 내는 명령은 여러 가지입니다. `chmod 750` 과 `chmod u=rwx,g=rx,o=` 는 결과가 같고, 사용자를 만들 때 옵션 순서를 바꿔도 결과는 같습니다. 실제 시험도 명령이 아니라 시스템에 남은 결과를 봅니다. 그래서 채점은 실행이 끝난 뒤의 상태를 봅니다. 파일의 권한 비트, 소유자와 그룹, 계정의 보조 그룹과 잠금 여부, 저장된 파일의 내용이 조건과 맞는지를 확인합니다.

이 방식은 셸 연습장을 처음 만들 때 이미 한 번 필요성을 확인했습니다. 권한 과제를 직접 풀다가 `chmod -x` 를 먼저 한 뒤 기호 모드를 쓰니 결과 숫자가 기대와 달라 통과하지 못한 일이 있었습니다. 그때 판정을 "정확한 숫자"에서 "조건을 만족하는 상태"로 바꿨고, 실기 문제는 처음부터 그 기준으로 만들었습니다.

## 대표 실수는 테스트로 고정

결과로 채점하면 "틀린 답이 우연히 통과하는" 경우도 막아야 합니다. 수험자가 자주 하는 실수를 골라, 그 실수를 하면 반드시 오답이 되도록 테스트로 묶었습니다.

- `usermod -G` 에서 `-a` 를 빼서 기존 보조 그룹이 지워지는 실수
- SetUID 파일을 찾을 때 `-perm -4000` 대신 `-perm 4000` 을 쓰는 실수
- `chown` 에서 `-R` 을 빼서 디렉터리 안쪽은 그대로 남는 실수
- `useradd` 의 `-g`(기본 그룹)와 `-G`(보조 그룹)를 헷갈리는 실수
- `userdel` 에서 `-r` 을 빼서 홈 디렉터리가 남는 실수

예외도 하나 있습니다. "처음부터 권한을 정해 디렉터리 만들기"는 문제 자체가 `mkdir -m` 을 연습하는 것이라, 디렉터리를 만든 뒤 `chmod` 로 고친 경우는 정답으로 치지 않습니다. 이 문제만은 디렉터리를 만든 명령에 `-m` 이 있었는지도 봅니다.

## 문제도 실제 Rocky Linux 8.8 로 대조

셸 연습장의 원칙은 실기 문제에도 그대로 적용했습니다. 문항마다 처음 상태를 만드는 명령, 모범 답안, 확인 명령을 실제 Rocky Linux 8.8 컨테이너에서 실행해 출력을 골든으로 남기고, 시뮬레이터가 같은 결과를 내는지 비교합니다. 실기 문제 15개 각각이 골든 시나리오 하나씩을 가집니다.

코드 리뷰에서는 연습 셸 준비 단계의 빈틈이 나왔습니다. 문제 글에서 `-aG wheel` 같은 옵션 묶음을 읽을 때 `wheel` 을 사용자 이름으로 잘못 읽어 가짜 사용자가 생기던 문제가 있었습니다. 옵션 값으로 읽도록 고쳤고, 준비 명령이 실패해도 셸은 열리게 했습니다. 또 `chmod -w` 처럼 옵션 자리에 쓴 모드가 umask 때문에 기대와 다르게 적용되는 경우, GNU chmod 는 경고를 내고 종료 코드 1 로 끝납니다. 이 동작도 컨테이너에서 확인한 뒤 똑같이 맞췄습니다.

## 퀴즈 해설에서 바로 쳐 보기

실기 문제와 같은 시기에 퀴즈에도 셸을 붙였습니다. 리눅스 문항의 해설 아래에 보기에 나온 명령을 칩으로 보여 주고, 누르면 그 명령이 건드리는 파일·사용자·그룹을 미리 만들어 둔 연습 셸이 펼쳐집니다. 시뮬레이터 엔진은 버튼을 눌렀을 때만 내려받아 페이지가 무거워지지 않게 했습니다. 명령이 없는 문항은 같은 주제의 단계별 실습으로 연결합니다. 일 단위 노트의 퀴즈, 오답 복습, 모의고사 연습 모드에 모두 들어가 있습니다.

이 작업을 하며 시뮬레이터도 더 정확해졌습니다. `find -atime`·`-ctime`·`-amin`·`-cmin` 과 잘못된 값을 넣었을 때의 오류 문구를 더했고, `-a` 처럼 모드 모양을 한 옵션을 모드로 읽는 GNU chmod 의 규칙도 맞췄습니다. 실습의 처음 상태에서 시계를 되돌려 둔 탓에 `ls -l` 이 시각 대신 연도를 찍던 문제도 이때 찾아 고쳤습니다. 모두 실제 컨테이너의 출력으로 확인한 뒤 반영했습니다.
